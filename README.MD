# STM32_Driver_development 
Develop drivers of STM32F746g-disco from scratch

## Peripheral Used 
### Arm Cortex-M7
- [x] FPU
- [x] Systick
- [x] NVIC
- [x] Priority Group
### MCU
- [x] GPIO
- [x] I2C 
- [x] SPI
- [x] USART
- [x] EXTI
- [x] RCC
